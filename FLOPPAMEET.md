# FloppaMeet Android client

This repository is a FloppaMeet client built on the Telegram Android open-source codebase.
It adds a native FloppaMeet sign-in/register screen and connects the workspace view to
`https://floppameet.mizodevelopment.com`.

The current preview APK is an arm64 debug build. The upstream Telegram source and license
notices remain included; this derivative is distributed under the applicable GPL-2.0 terms.

The Android client is an early preview: the FloppaMeet workspace shell is functional, while
the full Telegram feature set and richer FloppaMeet UI will be added incrementally.
